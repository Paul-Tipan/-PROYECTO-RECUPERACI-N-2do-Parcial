# PROYECTO RECUPERACION - 2do Parcial / PROYECTO INTERCICLO

## Descripción del Proyecto
Este proyecto consiste en el control de un módulo automotriz (Jetronic / Bus CAN) mediante un **Arduino**, un módulo **MCP2515 (CAN Bus)** y un módulo **Bluetooth HC-05**, controlado desde una aplicación móvil para Android.
